# NetCity

**A live 3D network map that turns your local network into a living city.**

NetCity discovers devices on your network, collects useful information about them, and visualizes everything as an interactive 3D city. Each device becomes a building. The city updates in real time as devices join, leave, or change state.

---

## Features (Roadmap)

- Discover devices on your local subnet
- Collect IP address, MAC address, hostname, vendor, open ports, and more
- Live 3D visualization (Godot) – devices appear as buildings
- Click any device to see detailed information
- Signal strength visualization
- Network overview (gateway, subnet, network type, etc.)
- Cross-platform (Linux, macOS, Windows)
- Runs with proper privilege handling (sudo / Administrator)
